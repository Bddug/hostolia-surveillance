# Surveillance des sites Hostolia

Toutes les 10 minutes environ, GitHub vérifie depuis l'extérieur que les sites répondent :

- https://dwellingverify.com (site et serveur)
- https://myrentalfigures.com (site et serveur)

Si un site ne répond pas après 3 essais, le contrôle échoue et GitHub envoie un e-mail.
Historique : onglet **Actions**. Tester une autre adresse : **Actions → Surveillance des sites → Run workflow**.
